## 进阶概念

### 异常处理
` python
try:
    # 可能出错的代码
except SpecificError as e:
    # 处理具体错误
except Exception as e:
    # 兜底处理
finally:
    # 不管对错都执行
` 

### 文件操作
` python
# 读
with open("file.txt", "r", encoding="utf-8") as f:
    content = f.read()

# 写
with open("file.txt", "w", encoding="utf-8") as f:
    f.write("内容")
` 

### with 语句
- 作用：自动管理资源的开关
- 用在：文件、数据库、Playwright
- 好处：即使报错也会自动关闭

### OOP 面向对象
` python
class Dog:
    def __init__(self, name):  # 构造方法
        self.name = name        # 实例属性

    def bark(self):             # 实例方法
        print(f"{self.name}叫了")

d = Dog("旺财")  # 创建实例（加括号！）
d.bark()
` 

### 装饰器
- 作用：在不改原函数的情况下增加功能
- 本质：函数接收函数，返回新函数

### 生成器
- yield：暂停函数，返回值，下次调用接着跑
- 节省内存，适合大数据处理

` python

## RESTful API 约定

| 操作 | 方法 | URL | 函数名 |
|------|------|-----|--------|
| 获取列表 | GET | /users | get_users() |
| 获取单个 | GET | /users/1 | get_user(id) |
| 创建 | POST | /users | create_user(data) |

## 方法使用速查（接收什么 / 返回什么 / 什么时候用）

### 字符串方法
| 方法 | 接收 | 返回 | 什么时候用 |
|------|------|------|-----------|
| strip() | 无 | 新字符串 | 去首尾空格 |
| split("") | 分隔符 | 列表 | 字符串→列表 |
| join() | 列表 | 字符串 | 列表→字符串 |
| replace("a","b") | 旧值,新值 | 新字符串 | 替换内容 |
| re.sub(r"\d","") | 正则,替换值 | 新字符串 | 正则替换 |

### 列表/字典方法
| 方法 | 接收 | 返回 | 什么时候用 |
|------|------|------|-----------|
| append(item) | 一个元素 | 无 | 往列表末尾加一个 |
| extend(list) | 一个列表 | 无 | 把另一个列表合进来 |
| get(key, default) | 键,默认值 | 值 | 取值，找不到不报错 |
| keys() / values() | 无 | 列表 | 获取所有键/值 |

### 文件/数据库方法
| 方法 | 接收 | 返回 | 什么时候用 |
|------|------|------|-----------|
| open("f","r") | 路径,模式 | 文件对象 | 打开文件 |
| f.read() | 无 | 字符串 | 读全部内容 |
| f.write("x") | 字符串 | 写入字符数 | 写内容 |
| writerow(row) | 一行数据 | 无 | CSV写一行 |
| writerows(rows) | 多行数据 | 无 | CSV写多行 |
| execute(sql) | SQL语句 | 游标 | 执行一条SQL |
| executemany(sql,data) | SQL,多条数据 | 游标 | 批量插入 |
| commit() | 无 | 无 | 提交事务 |

### 测试/自动化方法
| 方法 | 接收 | 返回 | 什么时候用 |
|------|------|------|-----------|
| assert x == y | 两个值 | 无 | 断言相等 |
| page.locator(sel) | 选择器 | Locator对象 | 先定位元素 |
| locator.fill(text) | 文字 | 无 | 往输入框填字 |
| locator.click() | 无 | 无 | 点击元素 |
| page.goto(url) | 网址 | 响应 | 打开网页 |

## 理解任何方法的三个问题

学新方法时问自己：
1. 它**接收**什么参数？（括号里放什么）
2. 它**返回**什么？（能拿到什么结果）
3. **什么时候**用它？（和相似方法的区别）

搞清这三点就不会用错。
